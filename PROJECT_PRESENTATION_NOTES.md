# FoodLens — Presentation Notes

## Problem Statement
Food delivery platforms generate large volumes of transactional data. Raw data is difficult to interpret directly, so the project converts it into visual analytics and useful business insights.

## Objectives
1. Clean and prepare food-delivery data.
2. Analyze orders, revenue, customers, food categories and delivery performance.
3. Build interactive visualizations.
4. Surface key patterns automatically.
5. Provide a web-based interface for exploring the data.

## Technologies
Python, Pandas, NumPy, Plotly, Streamlit.

## Demo flow
1. Open Overview.
2. Explain KPI cards.
3. Show monthly order trend.
4. Open Revenue.
5. Show Customer Analytics.
6. Show Delivery vs Rating.
7. Upload a different CSV.
8. Explain the data pipeline.
