# 🍔 FoodLens — Food Delivery Data Analysis System

A presentation-ready Python data analytics dashboard for the **Data Analysis Essentials** project.

## ✨ Features

- Modern dark analytics dashboard
- Interactive Plotly charts
- Revenue and order trends
- Customer analytics
- Delivery-time and rating analysis
- Food category and location analysis
- CSV upload
- Dataset quality summary
- Auto-generated key insights
- Included sample dataset
- GitHub + Streamlit Cloud ready

## 🚀 Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open the local URL shown by Streamlit.

## ☁️ Deploy from GitHub

1. Create a GitHub repository.
2. Upload this entire project folder.
3. Go to Streamlit Community Cloud.
4. Connect the GitHub repository.
5. Select `app.py` as the main file.
6. Deploy.

No database or environment variables are required for the included version.

## 📊 Dataset

The included sample dataset is in:

`data/food_delivery_sample.csv`

You can also upload your own CSV from the dashboard sidebar.
